# US Rent Tools

Free, client-side US rent calculators: prorated rent, rent increase caps, security deposits, late fees, move-in costs, and lease renewal comparison.

- No sign-up, no login, no paid packages or upgrades
- Static HTML/CSS/JS, no build step
- General information only, not legal advice. City ordinances may override state rules.

## Deploy

Deploy the root of this repo as a static site on Vercel. No custom domain yet — use the Vercel-provided URL.
